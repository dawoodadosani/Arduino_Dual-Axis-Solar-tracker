# Arduino Dual-Axis Solar Tracker

## Overview
A two-axis light-tracking system that automatically adjusts its position toward the strongest light source using sensors and servo motors.

## Features
- Horizontal and vertical light tracking
- Arduino-based control system
- Real-time sensor processing
- Custom 3D-printed mounting components

## Technologies
- Arduino
- C++
- Servo Motors
- Light Sensors
- 3D Printing

## How It Works
The Arduino reads light intensity from multiple sensors and compares the values to determine the direction of the strongest light source. Servo motors then adjust the system horizontally and vertically.

## Testing
The system was tested using a smartphone flashlight and successfully followed the light source in both axes.
